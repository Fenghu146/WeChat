# reports 文档索引

本目录集中存放课程设计的全部说明文档：正文为 Markdown，图见 `figs/`，
历史草稿见 `archive/`。课程任务书原文见 `docs/2026-面向对象程序课程设计.{md,docx}`。

| 文档 | 内容 |
|---|---|
| `实验报告.md` | 主实验报告（设计任务分析 / 方案 / 详细设计 / 测试 / 总结与最新进展） |
| `项目设计文档(C++).md` | 群组管理部分的设计文档（权限矩阵、时序图、模板方法说明） |
| `实现计划与验收清单.md` | 模块划分、实现顺序、接口约定与验收清单 |
| `类图.md` | 全量类图（Mermaid，含关键时序） |
| `测试报告.md` | 11 套件 123 用例逐项结果、需求覆盖度与代码质量检验 |
| `测试报告_边界与鲁棒性专项.md` | 边界与鲁棒性专项：鲁棒性缺陷修复记录与验证 |
| `设计验证报告.md` | 对照任务书「设计步骤」四步逐条核对 |
| `任务书逐条对齐.md` | 对照任务书逐条核对：题目描述 1~6、技术层次 1~5、设计步骤 1~4 的实现与测试证据 |
| `演示与手动验证指南.md` | 构建 / 测试 / 分段演示命令、工作台按键地图、逐项走查清单 |

## 子目录

- `figs/`：图片资源，`class_diagram_fh.png` 为类图导出。
- `archive/`：历史草稿，不再维护 —— `实验报告（初稿）.md` / `.docx`、
  `实验报告（终稿）.md`、`《面向对象程序课程设计》实验报告.docx`；
  主报告以 `实验报告.md` 为准。
